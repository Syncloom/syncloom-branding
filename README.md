# Syncloom branding

Icon sources and the generator for every platform's assets (macOS .icns, iOS, Android, Windows .ico, Linux hicolor, web favicons and monochrome glyphs).

Part of [Syncloom](https://github.com/Syncloom).

```bash
./build.sh        # regenerates dist/
```

The icon shows two interlocked, woven rings on an indigo-to-teal squircle.
